# Portfolio — Hayoub Mouffok

Site statique (HTML/CSS, sans framework ni JavaScript), déployé par Netlify à chaque push sur `main`.

- **CI** (GitHub Actions) : validation HTML (html-validate) et vérification des liens (lychee).
- **Sécurité** : en-têtes HTTP stricts définis dans `netlify.toml` (CSP, HSTS, anti-clickjacking).
